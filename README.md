## Features

- **Cinematic Animations**: Powered by GSAP ScrollTrigger and Framer Motion for a premium SaaS-level experience.
- **Smooth Scrolling**: Integrated Lenis for a buttery-smooth, inertia-based scrolling experience.
- **Perfectly Responsive**: Pixel-perfect layout across mobile, tablet, and desktop devices.
- **Multi-Page Routing**: Clean navigation architecture using React Router with lazy loading.
- **Modern Design System**: Built with Tailwind CSS v4 featuring glassmorphism and custom glow accents.
- **Spotlight Cursor**: Interactive custom cursor that enhances user engagement.
- **Blazing Fast**: Optimized with Vite for near-instant load times and high Lighthouse scores.

## Tech Stack

### Frontend
- **React 19**: Modern component-based architecture.

## Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/antick-arch/My-Portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd My-Portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

## 📁 Project Structure

```text
src/
├── assets/          # Images, icons, and static files
├── components/      # Reusable UI components (Hero, Navbar, etc.)
├── layout/          # Layout wrappers (MainLayout)
├── pages/           # Individual route pages (Home, Projects, etc.)
├── index.css        # Global styles and Tailwind directives
├── App.jsx          # Multi-page routing configuration
└── main.jsx         # React application entry point
```
